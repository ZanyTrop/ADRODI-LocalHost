\# ADROBI — язык и среда Adrobi Studio



Всё приложение — один файл `index.html`: редактор, интерпретатор, авто-фикс, ИИ-помощник.



\## Запуск

\- Двойной клик по `index.html`, или

\- `python -m http.server 8000` → http://localhost:8000



\## Деплой

1\. GitHub: New repository → загрузить `index.html` и `README.md` → commit

2\. Vercel: Import repository → Framework: Other → Deploy



\## Синтаксис ADROBI

&#x20;   act main            — точка входа

&#x20;   let num x 5         — переменная (типы: num, text, dot)

&#x20;   echo hello world    — вывод

&#x20;   when x more 3       — условие (more / less / same)

&#x20;   or                  — иначе

&#x20;   loop 3              — повторить N раз

&#x20;   back 0              — вернуть значение

&#x20;   stop                — конец блока

&#x20;   sum diff mul div    — математика



\## Файлы .adb

\- «сохранить» или Ctrl+S → скачивает `program.adb`

\- «загрузть» → открывает `.adb` для дальнейшей работы



\## Фишки

\- Авто-фикс: опечатки чинятся сами, код правится в редакторе, тест повторяется

\- ИИ: пустой экран → шаблон; код → анализ (повторы, лишние переменные, нехватка stop/act main)

\- Защиты: бесконечный цикл и глубокая рекурсия не повесят браузер

\- Адаптив: узкий экран — панель уезжает вниз

\- Горячие клавиши: Ctrl+Enter — запуск, Ctrl+S — сохранить



\## Дизайн

Чёрный фон, JetBrains Mono, подсветка: команды — мятный, типы — лавандовый, echo — персиковый, строки — золотой. Курсор — белый блок, следует за вводом.
